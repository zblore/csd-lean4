## CR-LF2-001: support a moving projected state

The old convenience lemmas required `π (Φ x) = π x`: every projected ray stays fixed.
That is stronger than projectability `π (Φ x) = φ (π x)` for a projected map `φ`.

Added `outcomeOfProjective_preEvent_of_projectable`, proving that the pre-event is
`π ⁻¹' (φ ⁻¹' Oep)`, and its measurable-map weight companion. The old lemmas now
specialize these results to `φ = id`, retaining their signatures. The existing
`LF1_main_theorem_projective` already accepts the resulting correspondence when its
projective region is `φ ⁻¹' Oep`; no duplicate terminal theorem is introduced.

This is an interface extension, not evidence that the old theorem was false. It does
not silently generalize downstream LF3 statements that still assume fixed rays;
that separate review obligation is CR-LF2-006.

## CR-LF2-002: derive the bridge normalization

For a probability reference measure, evaluating `bridge_eq` on the whole space proves
`bridge.c = D.μL Set.univ` (`c_eq_measure_univ`). If the ontic measure is also a
probability measure, `c_eq_one` follows. Normalization is therefore not an independent
physical premise in that setting. The old `fromPreparation_liouville_apply` keeps its
explicit `hc` argument for compatibility; callers can now supply `bridge.c_eq_one`.

No attempt was made to delete the intentionally retained bridge argument from
`fromPreparation`: the earlier F-01 disposition explicitly chose transport theorems.

## CR-LF2-003: expose surjectivity and correct the setup description

A nonempty source, an equivariant projection and a transitive target imply that the
projection is onto: translate one source point so that its image reaches any target.
`SectorData.surjective_π` proves this without an additional field or measure assumption.
The proof uses pinned Mathlib's `MulAction.exists_smul_eq`.

Removed retired SO-1 framing and the stale claim that the concrete special-unitary
instantiation was future work. The existing `LF4/Instance.lean:cpSectorData` uses
`Matrix.unitaryGroup`, with identity projection on complex projective space. This
bundle does not derive the ontic surface; the charter's objective is unchanged.

## Wider follow-up obligations

**CR-LF2-005 — representative independence.** PhaseInvariance proves invariance of
outer products and rank-one wrappers. Its header says this justifies `effectProjFn`
under arbitrary phase choices, but the current effect-function API has no explicit
phase-change theorem. Add, for example, equality of `effectProjFn rep E` and
`effectProjFn (fun p => c p • rep p) E` when every `c p` has norm one; then connect
that result to the preparation integral. Arbitrary unrelated representative maps
need not give equal values. Review the phase module and its downstream claims before
closing this item. This is an absent connection, not a counterexample to existing proofs.

**CR-LF2-006 — downstream projected dynamics.** During the LF3/flow review, trace
which callers really need fixed rays and which should state general projectability.
Use the new pullback identity to strengthen the appropriate existing theorem where
its other hypotheses support the intended dynamics. Do not replace `Oep` by its flow
pullback in a Born claim without proving the matching weight identity.

Other observations: ontic-action measurability is redundant with the preservation
field, but removing it would churn constructors without a demonstrated review benefit.
The pure-preparation unit-vector hypotheses exclude dimension zero; the direct proof
needs no additional lower bound, whereas the retained trace-form API states `2 ≤ N`.
Existing concrete LF2 bridge witnesses provide nonvacuity for the abstract bundles;
those witness files are build consumers, not additional full-review credit in this batch.
