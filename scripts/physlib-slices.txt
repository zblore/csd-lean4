# scripts/physlib-slices.txt — the concept slices of the Physlib export.
#
# One line per module of the export closure: `<slice-name><TAB><module path under CsdLean4.Mathlib.>`.
# Slices appear in the order their first line appears; scripts/export_physlib.py checks that
# every module of the closure is listed and that every import lies in the same or an earlier
# slice, so each slice is a self-contained Physlib PR on top of the ones before it. A slice is a
# concept, not a size: Physlib's review guidelines prefer PRs of roughly 200 lines, so several
# slices will be split further at PR time (the table `export-physlib.sh --table` flags them).
# The mirror of PR #1652's FisherRao.lean is listed so the build projects compile while that PR
# is open; the exporter never puts it in a PR slice.
